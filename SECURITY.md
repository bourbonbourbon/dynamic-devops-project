# Security Policy

## Supported versions

Only the latest release on the `main` branch receives security fixes.

## Reporting a vulnerability

Do not report security vulnerabilities in public GitHub issues.

Report them in one of these ways:

- Use GitHub private vulnerability reporting:
  https://github.com/bourbonbourbon/dynamic-devops-project/security/advisories/new
- Send an email to bourbonbourbon@example.com

Include these details in your report:

- a description of the vulnerability and its impact
- the steps to reproduce it
- the version or commit that you tested

## Disclosure process

1. We confirm receipt of your report within 7 days.
2. We check the report and tell you whether we accept it.
3. We prepare a fix and a release.
4. We publish the fix and a security advisory. We ask you to keep the details private until then.

We aim to publish a fix within 90 days of the report. For a serious issue, we aim for a shorter time.

## Scope

This project is a learning project. It is not used in production. The scope covers the code in this repository, the Dockerfile, and the Kubernetes manifests.
